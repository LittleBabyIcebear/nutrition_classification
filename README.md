# Child Nutritional Status Prediction (Gizi Balita)

This project predicts the nutritional status of children (toddlers) — classifying them as **Normal**, **Stunted**, **Severely Stunted**, or **Tall** — using machine learning.

A key challenge in the source data was the absence of *weight*, a critical feature for nutritional analysis. This project implements a **two-stage modeling pipeline** to solve this:
1.  A **Random Forest Regressor** is trained on a separate, complete dataset to accurately predict a child's weight.
2.  This trained regressor is then used to generate the missing weight feature for the primary dataset.
3.  A **K-Nearest Neighbors (KNN) Classifier** is trained on this newly augmented dataset to predict the final nutritional status.

The project includes a **FastAPI** application (`gizi_api.py`) to serve the trained model via a REST API, supporting both single and batch predictions.

## Project Overview

The goal of this project is to build a reliable classifier for child nutritional status. The primary dataset (`data_balita.csv`) contained a child's age, height, gender, and their corresponding nutritional status, but lacked their weight.

To overcome this, a two-stage pipeline was developed. First, a regression model was built using `data_gizi.csv` to predict weight. This model was then used to augment the primary dataset with a `Predicted Weight` feature. Finally, a classification model was trained on this complete dataset.

### **Features (Input)**
* `usia` (Age in months)
* `tinggi_badan` (Height in cm)
* `jenis_kelamin` (Gender)
* `Prediksi Berat Badan` (Predicted Weight in kg - *generated by Stage 1 model*)

### **Target (Output)**
* `Status Gizi` (Nutritional Status)
    * `normal`
    * `stunted`
    * `severely stunted`
    * `tinggi` (Tall)

## Methodology

### Stage 1: Weight Prediction (Regression)

A `RandomForestRegressor` was trained on the `data_gizi.csv` dataset (138 samples) to predict `berat_badan` (weight) using age, height, and gender.

* **Model:** `RandomForestRegressor(n_estimators=100, random_state=42)`
* **Performance:**
    * **Mean Absolute Error (MAE):** 0.61 kg
    * **R-squared (R²):** 0.9139

This model (`rf_model`) demonstrated high accuracy and was saved to be used as a feature generator.

### Stage 2: Nutritional Status Prediction (Classification)

The trained `rf_model` was used to predict the weight for all 39,425 entries in the `data_balita.csv` dataset. This new `Predicted Weight` column was added, and the resulting `data_balita_include_bb.csv` file was used to train the final classifier.

* **Features:** `Age`, `Height`, `Gender`, `Predicted Weight`
* **Target:** `Status Gizi`
* **Preprocessing:**
    * Categorical features (`Gender`, `Status Gizi`) were encoded using `LabelEncoder`.
    * Numerical features (`Age`, `Height`, `Predicted Weight`) were scaled using `StandardScaler`.
* **Model:** `KNeighborsClassifier`
* **Hyperparameter Tuning:** `GridSearchCV` was used to find the optimal parameters.
    * **Best Parameters:** `{'metric': 'euclidean', 'n_neighbors': 3, 'weights': 'distance'}`

## How to Run

### 1. Run the Jupyter Notebook (Training)

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/your-username/your-repo-name.git](https://github.com/your-username/your-repo-name.git)
    cd your-repo-name
    ```

2.  **Create a virtual environment and install dependencies:**
    ```bash
    python -m venv venv
    source venv/bin/activate  # On Windows: venv\Scripts\activate
    pip install -r requirements.txt
    ```

3.  **Run the Jupyter Notebook:**
    ```bash
    jupyter notebook knn_gizi_ver2.ipynb
    ```
    Running all cells will execute the full training pipeline, perform analysis, and save the final model artifacts (`.joblib` files) to the root directory.

### 2. Run the API (Inference)

After running the notebook and generating the `.joblib` files, you can run the API server.

1.  **Ensure all dependencies are installed:**
    ```bash
    pip install -r requirements.txt
    ```

2.  **Start the Uvicorn server:**
    ```bash
    uvicorn gizi_api:app --reload
    ```
    The API will be available at `http://127.0.0.1:8000`.

## API (FastAPI)

The API provides three endpoints for interacting with the model.

### `GET /`

Returns a simple welcome message.
* **Response:** `{"message": "API Prediksi Status Gizi Balita"}`

### `POST /predict`

Predicts the nutritional status for a single child.

* **Input (JSON Body):**
    ```json
    {
      "umur_bulan": 24,
      "jenis_kelamin": "laki-laki",
      "tinggi_badan_cm": 85.5,
      "berat_badan_kg": 12.0
    }
    ```
    *(Note: `jenis_kelamin` must be either `laki-laki` or `perempuan`)*

* **Output (JSON Response):**
    ```json
    {
      "prediksi_status_gizi": "normal"
    }
    ```

### `POST /predict-batch`

Predicts the nutritional status for multiple children via a CSV file upload.

* **Input:** `multipart/form-data` (upload a CSV file).
* **CSV File Format:** The file *must* contain these exact columns in this specific order:
    1.  `Umur (bulan)`
    2.  `Jenis Kelamin`
    3.  `Tinggi Badan (cm)`
    4.  `Prediksi Berat Badan (kg)`

    You can use `test_data.csv` in this repository as an example.

* **Output (JSON Response):**
    ```json
    {
      "total": 2,
      "prediksi": [
        {
          "index": 0,
          "prediksi_status_gizi": "normal"
        },
        {
          "index": 1,
          "prediksi_status_gizi": "stunted"
        }
      ]
    }
    ```
